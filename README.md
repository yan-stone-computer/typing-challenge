# 字速挑战 · 个人打字挑战

一个单文件的中文/英文打字挑战网页，用于社团活动现场的个人成绩记录。纯前端实现，无需服务器和数据库，直接把文件放进静态托管即可运行。

## 功能

- 进场登记学号、名字、学院、专业，并通过访问密码解锁
- 中文 / English 两种题库，每局随机抽取一篇长文本（中文均 150 字以上）
- 实时显示速度、准确率、完成进度与用时
- 结束后按 `完成度 ×（速度 45% + 准确率 55%）` 计算综合分（满分 100）
- 成绩页展示参赛信息与各项数据，可截取整屏保存到桌面
- 保存成功后自动锁回首页，方便下一位参与者使用
- 每人的最佳成绩与最近记录保存在浏览器本地

## 使用

直接用浏览器打开 `index.html` 即可。若要使用完整功能（全屏截图、保存到桌面），请通过 HTTPS 访问，并使用 Chrome 或 Edge。

访问密码写在 `index.html` 中，如需修改，搜索 `gjjapp666` 替换即可。

## 部署到 GitHub Pages

1. 新建仓库并上传本目录全部文件
2. 仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`

## 已知限制

- 密码校验在前端完成，属于防误入，不是真正的权限控制；页面源码中可以看到密码
- 成绩记录保存在浏览器本地存储中，按「学号 + 语言」分开，换电脑或清缓存后不跟随
- 手机与平板浏览器通常不支持网页截取整屏，建议在电脑上使用
